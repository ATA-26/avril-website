# Avril Solutions LLC — Website

Static marketing site for Avril Solutions LLC, a nationwide cash home-buying company based in Seattle, WA.

## Pages
- `index.html` — Home / cash-offer landing
- `how-it-works.html` — Process (cash vs. novation)
- `about.html` — About & team
- `faq.html` — Frequently asked questions
- `contact.html` — Contact & lead form

Assets: `styles.css`, `script.js`, `assets/logo.png`, `assets/logo-white.png`.

## Hosting
Served via **GitHub Pages** (branch `main`, root folder) on the custom domain **avrilsolutionsnw.com** (DNS managed at Squarespace). The `CNAME` file sets the custom domain.

## Note
The contact/lead form (`script.js`) is currently a front-end demo — submissions are not stored or emailed. Wire it to a form service (e.g. Formspree) or CRM to capture real leads.
